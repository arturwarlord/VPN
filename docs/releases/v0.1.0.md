# FreeRoute v0.1.0 — first pre-release

This file is a versioned release request. Pushing this commit on the branch `release/v0.1.0` triggers the verified multi-platform release workflow.

This version is explicitly a pre-release:
- Android APK: debug/testing build.
- Windows package: x64 testing build.
- iPhone: unsigned inspection package; not directly installable as a working VPN.
- The FreeRoute VPN exit server is not yet deployed. No country switching or leak protection is guaranteed.

The release workflow attaches all platform build artifacts and SHA-256 checksums only after all three build jobs succeed.
