Перед установкой

Что важно знать

01 / СТАТУС

Приложения — тестовые

Успешная сборка подтверждает, что приложение компилируется. Она не подтверждает работу реального туннеля или безопасность соединения.

02 / СЕРВЕР

VPN-сервер ещё не запущен

Публичный сервер вне России, стабильное подключение и проверка DNS/IP на реальных устройствах остаются следующими этапами.

03 / ОБНОВЛЕНИЯ

Публикация версий через Releases

Версии будут содержать приложения, контрольные суммы SHA-256 и описание изменений. Тестовые сборки остаются в GitHub Actions.
